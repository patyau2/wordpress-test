# WordPress Test — a hosted-preview experiment

## What this is — read this before you touch anything

**A WordPress site used to try out the hosted-preview approach for RLX client work.** WordPress core
sits in this folder with a custom homepage; `blueprint.json` and `preview-blueprint.json` drive a
WordPress Playground preview, which is the actual thing being tested — can a client see a working
site without hosting being set up first.

**Nobody uses it. It is a scratch project** — two commits, last touched 2026-08-07, styled after a
"Smart Hearing" site as a stand-in. No client is looking at it and nothing here is live.

**It belongs to RLX** as an experiment for the client-site offer.

**What must not break:** nothing. Treat it as disposable.
